# ThePaldex — Product

## One-liner

Unofficial **Palworld 1.0 toolkit**: role tier lists, breeding calculator, team
builder, Paldeck, and scenario-first interactive map — monetized with ads
without killing tool usability.

## Pillars

| Pillar | Job | Primary URL |
| --- | --- | --- |
| **Tiers** | Best pals by role (combat, work, mounts, capture) | `/tiers` |
| **Breeding** | Predict eggs / find parents for a target | `/breeding` |
| **Teams** | Meta comps + party of 5 | `/teams` |
| **Paldeck** | Stats, work, skills per pal | `/pals`, `/pals/[slug]` |
| **Map** | Hunt alphas/towers, find spawns, collect, travel | `/map` |

Supporting: `/news`, `/blues` (dev notes).

## Positioning

- **Is** a fast meta toolkit players return to after patches.
- **Is** curated catalog + reasoned tier notes + shareable tool URLs.
- **Is not** an achievement completion tracker (legacy pivot — do not revive).
- **Is not** a Fandom lore dump or scraped Steam guide paste.

## Audience

1. Players optimizing combat / base / mounts after 1.0.
2. Breeders planning parent chains.
3. Collectors hunting alphas, effigies, notes on the map.
4. Reddit / Discord users who want a clean tool link, not a wiki wall.

## Success metrics

- Session depth ≥3 pageviews (tool → pal → related tool).
- Time-to-value &lt;10s on hubs (tiers / breeding / map mode).
- SEO entries on tool queries that convert into multi-tool sessions.
- Ad health: impressions/session up without bounce spike.

## Explicitly defer

- Achievement tracker / Steam achievement sync.
- Exhaustive lore / recipe wiki.
- Mass AI guide farms.
- Multi-game trackers.
- RU locale before EN SEO is stable.
